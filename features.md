# Meridian features

Record new features and user-visible improvements under the date they are added, using `YYYY-MM-DD` dates. Include relevant bug fixes and describe any material limitations.

## 2026-11-05

- Added Meridian Photos and Music & Video, and connected the built-in Calendar and Clock instead of launching GNOME substitutes. All four use responsive black surfaces with #00CC00 accents and appear in launcher search, taskbar pinning and desktop shortcuts. Photos opens local images into a searchable thumbnail library with previous/next, zoom and view-only rotation. Music & Video opens local files into a searchable queue with native seek/volume controls, previous/next and repeat-one; media decoding is enabled only for its WebView. Format support depends on installed codecs. Libraries/queues last for the retained app session, are not restored after shell restart, and media pauses when hidden.
- Restyled Calendar's keyboard-accessible month grid and locally persisted daily agenda; saves stay disabled until existing events load. Restyled Clock's local time, stopwatch/laps and silent timer, fixed pause-time precision and the completed countdown display. Calendar has no cloud sync or reminders; Clock has no background alarm service. Static source review only; no builds, automated tests, Node verification or live visual/media checks. Rebuild/install the UI and native shell to apply.

- Added on-demand native diagnostics for available memory, total memory, online logical CPUs, and Linux memory pressure, with explicit unavailable states.
- Added a headless `meridian-shell --engine-status` startup diagnostic and isolated tests for persisted font profiles, inherited configuration, and Fontconfig matching.
- Added graceful native preview allocation failures and preserved GTK's existing font settings when the scoped font profile cannot load.
- Extended reduced-transparency settings to application and file context menus; Efficient mode also disables decorative text filters, shadows, and strokes.
- Added a standalone native GTK Meridian Installer for install, update, repair, requirements checks, and confirmed removal, without a WebView or Node runtime in the GUI.
- Added `bash install.sh --gui`, an installed application launcher, and Settings → General → Open Installer. The GUI remembers the selected source checkout and keeps Git changes under user control.
- Added verified prepared-release installation (`--prepared`) to skip compilation and development-dependency setup. Runtime dependencies can still require package-manager work; source rebuilds are not instant.
- Added bounded progress logs, background installer execution, desktop Polkit authentication, and single-job/limited-Node-heap source-build defaults. The GUI never collects passwords or runs tests.
- Disabled installer log undo history so discarded output cannot accumulate outside the visible log limit.
- Added per-user operation locks and a system installation lock to prevent overlapping builds and system-file replacements; included the installer binary and launcher in transactional installation/rollback and release integrity metadata.
- Made `install.sh` graphical by default, with explicit `--cli` terminal operation and `--gui` as an alias. Graphical action flags preselect the corresponding operation rather than starting system changes automatically.
- Unified compilation and installation behind `install.sh`: normal install/update/repair builds and installs, while `--compile` creates a verified release without installing Meridian files. Added Compile only to the GUI and routed all GUI workers through the CLI backend to prevent recursive GUI launches.
- Improved incomplete-release errors to identify missing binaries (including the native installer) and direct users to the unified compile-and-install command before attempting checksum verification.
