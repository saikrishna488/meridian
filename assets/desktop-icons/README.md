# Meridian desktop icons

Meridian's built-in SVG icons are original artwork licensed under GPL-3.0-or-later, matching the project. See the repository `LICENSE`. They use a consistent rounded-square shape and clear, unbranded category glyphs.

Installed app artwork is rendered inside standardized rounded-square tiles. Meridian artwork stays fixed for Settings, Finder, Terminal, the launcher, Control Center, and Trash. Other apps use their installed desktop-entry icons from the hicolor theme, including host icon directories in toolbox sessions. Unmapped entries fall back to a letter icon.
